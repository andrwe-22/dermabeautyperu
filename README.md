# DermaBeauty Peru

نسخة ثابتة من الواجهة الرئيسية لموقع **DermaBeauty** المتخصص في dermatología clínica y estética والعناية بالبشرة في بيرو.

## محتوى المشروع

- `index.html`: الصفحة الرئيسية.
- `css/`: ملفات التنسيق والقوالب والمكونات.
- `js/`: ملفات JavaScript والتفاعلات الخاصة بالقوائم والمنتجات والسلة.
- `images/`: صور المنتجات والشعارات والمحتوى المرئي.
- `fonts/`: الخطوط والأيقونات المستخدمة في الواجهة.

## التشغيل محليًا

يمكن فتح `index.html` مباشرة في المتصفح، أو تشغيل خادم محلي من مجلد المشروع:

```bash
python -m http.server 8000
```

ثم افتح:

```text
http://localhost:8000
```

## ملاحظات

هذه النسخة تحتوي على الواجهة والموارد المحلية فقط. وظائف WordPress وWooCommerce الديناميكية، مثل تسجيل الطلبات والسلة والدفع، تحتاج إلى الخادم الخلفي الأصلي حتى تعمل بالكامل.
